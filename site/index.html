The AI converses. The rules decide.

Sentinel handles "I do not recognize this charge" in Spanish and Portuguese. It acts only when the policy allows it. It never invents a fact.

Five steps, each one checkable

1

Understand

A language model reads the request and labels the intent.

2

Look up

The code reads the real charges of the session account. The model sees no customer id.

3

Decide

The policy engine, in code, allows, refuses or hands off.

4

Verify

The code checks that the case exists before it says so.

5

Hand off

For fraud or a high amount, an advisor gets the verified facts.
