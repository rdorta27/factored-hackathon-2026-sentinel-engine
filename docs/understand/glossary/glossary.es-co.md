# Glosario — ES-CO

Overlay de Colombia sobre el [glosario canónico en inglés](glossary.en-us.md). El término local se conserva intacto; la explicación va en inglés para la entrega.

## Banking terms

| Concept | Colombian term (ES-CO) | English |
|---|---|---|
| Currency | COP (peso colombiano), + USD | Colombian peso and US dollar |
| ID documents | CC (*cédula de ciudadanía*), CE (*cédula de extranjería*) | Citizenship and foreigner ID cards |
| Checking account | Cuenta corriente | Checking account |
| Savings account | Cuenta de ahorro | Savings account |
| Statement | Estado de cuenta | Account statement |
| Balance | Saldo | Balance |
| Credit / debit card | Tarjeta de crédito / débito | Credit / debit card |
| Block the card | Bloquear la tarjeta | Block the card |
| Unrecognized charge | Cargo no reconocido | Unrecognized charge |
| Chargeback | Contracargo | Chargeback |
| Pre-authorization | Preautorización | Pre-authorization |
| Overdue | Mora, días de atraso | Overdue, days past due |
| Instant transfer | Transferencia | Bank transfer |

## Customer support

| Concept | Colombian term (ES-CO) | English |
|---|---|---|
| Call-center agent | Asesor, agente | Agent |
| Support center | Call center, centro de contacto | Contact center |
| Complaints system | PQR (*Peticiones, Quejas y Reclamos*) | Requests, complaints and claims system |
| Customer advocate | Defensor del consumidor financiero | Financial consumer advocate |
| Banking regulator | SFC (*Superintendencia Financiera de Colombia*) | Financial superintendence |
| "I want to talk to a person" | Quiero hablar con un asesor | I want to talk to an agent |
